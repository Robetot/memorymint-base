# Game Sound Effects

This folder contains the sound effects used in the memory game.

## Sound Files
- `flip.mp3` - Card flip sound (soft swoosh)
- `match.mp3` - Match success sound (pleasant chime)
- `mismatch.mp3` - Mismatch sound (soft, calm tone)
- `win.mp3` - Victory sound
- `lose.mp3` - Game over sound
- `click.mp3` - UI click sound
- `combo.mp3` - Combo bonus sound

## Notes
- All sounds are hosted locally for reliable loading
- Mismatch sound is intentionally subtle and pleasant
- Volume levels are pre-balanced for consistent experience
